# 💧 Consumo de Água

## 📌 Sobre o projeto

Este projeto foi criado para uma campanha de conscientização sobre o consumo de água.

O programa recebe o tipo de imóvel e o consumo mensal de água em m³. Depois, classifica o consumo e mostra uma mensagem de orientação.

## 🛠️ Tecnologias utilizadas

![Python](https://img.shields.io/badge/Python-3.x-blue?logo=python)
![GitHub](https://img.shields.io/badge/GitHub-Projeto-black?logo=github)

- 🐍 Python
- 💻 VS Code
- 🐙 GitHub

## ▶️ Como executar

1. Instale o Python.
2. Baixe ou clone este repositório.
3. Abra a pasta `consumo-agua` no VS Code.
4. Execute o arquivo `app.py`.
5. Digite o tipo de imóvel.
6. Digite o consumo mensal de água em m³.

## 💧 Exemplo

```text
=== Sistema de Consumo de Água ===
Digite o tipo de imóvel (comercial, casa ou apartamento): apartamento
Digite o consumo mensal de água em m³: 8

````

O objetivo do projeto é praticar programação em Python utilizando:

* Operadores lógicos
